# Nuraini Khadijah — Portfolio Website

A single-page responsive, static portfolio designed for Product Operations, Business Operations, Project Management and Analyst applications.

## Files
- `index.html` — content and layout
- `styles.css` — complete visual design and mobile layout
- `script.js` — working project category filters
- `favicon.svg` — browser icon

## Preview locally
Open `index.html` in a browser. No build command or dependencies needed. Google Fonts require internet access; the site has fallbacks.

## Deploy to GitHub Pages
1. Sign in to GitHub and create a **public** repository named `portfolio` (or `<your-username>.github.io`).
2. Click **Add file → Upload files**, then upload the *contents* of this folder (the HTML file needs to be at repository root), and commit.
3. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch **main**, folder **/(root)** and click **Save**.
5. GitHub Pages will publish at `https://<username>.github.io/portfolio/` (or `https://<username>.github.io/` for a special username.github.io repository).

## Edit content
Change the text in `index.html`, primarily sections with the classes `.project-copy`, `.about-text`, and `.recognition`. Edit colors at the beginning of `styles.css` under `:root`.
